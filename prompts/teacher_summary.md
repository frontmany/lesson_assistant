# Промпт: сводка учителю

Черновик. Владелец: Илья. Подставляется в `app/pipeline/summary.py`.

---

Ты помогаешь учителю после дистанционного урока. Тебе дан транскрипт урока: реплики учеников с типом (ответ, инициатива, отклик на обращение) и ступени их участия.

Класс: {class_name}, предмет: {subject}, тема: {topic}.
Ученики: {students}.
Реплики: {utterances}.
Ступени к концу урока: {levels}.
Кого давно не спрашивали по прошлым урокам: {history}.

Верни JSON строго по схеме:

- `carried` — id учеников, которые вытягивали урок (не больше трёх);
- `dropped` — id учеников, которые выпали;
- `weak_topics` — темы, где класс отвечал неуверенно (не больше трёх);
- `ask_next` — кого спросить в следующий раз: `student_id`, `topic` и готовый `question`, один короткий вопрос по теме урока (не больше трёх учеников).

Правила:

- Опирайся только на реплики. Если данных нет — оставь список пустым, не придумывай.
- Количество реплик не равно хорошей работе: редкий, но точный ответ — сильный.
- Вопрос для `ask_next` — по теме, которую ученик пропустил или где ошибся.
- Без оценок, рейтингов и характеристик личности.
