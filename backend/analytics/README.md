# Скрипты замеров

Скрипты прогоняют конвейер бэкенда на записях и считают цифры качества. Результаты описаны в `docs/quality.md`. Запускаются из папки `backend`, команда записана в начале каждого файла.

`compare_asr.py` сравнивает модели распознавания на живых фразах из `data/asr_check`.

`replay_kinds.py` прогоняет записанный урок без звонка и сверяет типы реплик с эталоном.

`summary_demo.py` собирает сводку и карточки записанного урока через GigaChat или по шаблону.
