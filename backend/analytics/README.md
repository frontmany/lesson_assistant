# Скрипты замеров

Python-скрипты, которые гоняют конвейер бэкенда на записях и считают цифры качества. Результаты и выводы — в [docs/quality.md](../../docs/quality.md).

Запуск — из папки `backend/`, команда в начале каждого файла:

| Скрипт | Что считает |
|---|---|
| `compare_asr.py` | сравнение моделей распознавания на живых фразах из `data/asr_check/` |
| `replay_kinds.py` | типы реплик на записанном уроке против эталонной разметки |
| `summary_demo.py` | сводка и карточки демо-урока через GigaChat или по шаблону |
