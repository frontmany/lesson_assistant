# Сертификаты

`russian_trusted_root_ca.pem` это корневой сертификат удостоверяющего центра Минцифры. Им подписан сертификат API MAX, а Python и Windows по умолчанию ему не доверяют. Сертификат используется только в запросах бота к API MAX и действует до 27.02.2032.

Источник сертификата Госуслуги, адрес `https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt`. Отпечаток SHA 256 такой.

```text
D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31
```
