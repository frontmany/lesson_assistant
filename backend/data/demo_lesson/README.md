# Записанный урок

Урок истории про реформы Петра I в 10А, около шести минут. На нём показывают демо и считают цифры качества. В звонок он заходит ботами, по боту на каждого участника.

Урок озвучен синтезом речи ElevenLabs по сценарию, у каждого говорящего свой голос. Синтез чище живой речи, в нём нет шума и перебиваний, поэтому на живом уроке распознавание ошибается чаще.

У учеников разные роли. Иван отвечает часто и по делу. Мария сама задаёт вопросы. Артём отвечает только на обращение и коротко. Софья отвечает на обращение длинно, но мало по делу. Алиса говорит редко, но точно. Дмитрий молчит весь урок.

## Файлы

В `roster.json` лежат класс, тема и участники. Имя дорожки совпадает с id участника.

В `tracks` лежат дорожки участников в WAV, 16 кГц, моно.

В `ground_truth.csv` лежит эталонная разметка реплик с точным временем из раскладки синтеза. Колонки там такие. `speaker_id` это участник, `start_s` и `end_s` начало и конец реплики в секундах, `text` текст, `kind` тип реплики, `addressed` единица, если это ответ на обращение учителя.

В `history_seed.json` лежат пять прошлых уроков класса. По ним считается норма урока и подсказка, кого спросить.

Дорожки хранятся в Git LFS. После клонирования их нужно скачать, иначе вместо звука будут ссылки.

```bash
git lfs install
git lfs pull
```
