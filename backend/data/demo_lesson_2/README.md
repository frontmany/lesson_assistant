# Второй записанный урок

Урок всеобщей истории про открытие Америки в 7Б, около шести минут. Первый записанный урок слишком гладкий, а этот собран из трудных мест, на которых правила шкалы чаще ошибаются.

## Трудные места

Учитель обращается к ученику по фамилии, по имени и фамилии и уменьшительным именем. В классе два Ивана, и иногда учитель зовёт одного из них только по имени. Ученица отвечает вместо того, кого спросили. Ученик отвечает неверно, а другой говорит не знаю. Один ответ приходит после долгой паузы. Ученица задаёт свой вопрос и один раз болтает не по теме. Двое начинают отвечать одновременно. Один ученик молчит весь урок, хотя его спрашивают, а на его дорожке только кашель и стук клавиатуры.

Эталонные типы реплик размечены по смыслу, а не по тому, что сейчас выдают правила.

## Файлы

В `scenario.csv` лежит сценарий, по реплике на строку, с паузами, наложениями и разметкой. Из него скрипт собирает дорожки.

В `roster.json` лежат класс и участники с полными именами и голосами.

В `tracks` лежат дорожки, а в `ground_truth.csv` эталон реплик. Их собирает скрипт.

В `history_seed.json` лежат пять прошлых уроков. Волков не отвечал на всех пяти, Белов на двух последних.

## Как собрать

Урок озвучивает Silero TTS бесплатно и без интернета после первой загрузки модели. Кашель и стук скрипт генерирует из шума, чужие записи не нужны. Команда запускается из корня репозитория.

```bash
docker run --rm -v "$PWD:/srv" -v lesson-tts-cache:/root/.cache -w /srv python:3.12-slim sh -c \
    "pip install -r scripts/requirements-tts.txt && python scripts/make_demo_lesson.py backend/data/demo_lesson_2"
```

Том `lesson-tts-cache` хранит модель между запусками. Если загрузка модели оборвалась, команду запускают ещё раз.
