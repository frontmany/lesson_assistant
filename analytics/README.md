# Замеры качества

Владелец: Илья. Цифры отсюда идут в README и на последний экран демо.

| Метрика | Как считаем | Цель |
|---|---|---|
| Точность распознавания (WER) | сравниваем текст конвейера с `ground_truth.csv`, доля ошибочных слов | чем ниже, тем лучше; честно показываем, какая получилась |
| Точность атрибуции | доля реплик, приписанных правильному ученику | 100% на записи; на живых звонках главное — найти, откуда берутся ошибки (эхо, чужой голос в микрофоне) |
| Точность типа реплики | доля реплик, где `kind` совпал с разметкой | от 70% |
| Задержка шкалы | время от конца реплики до события `scale` в браузере | меньше 1,5 секунды |
| Время сводки | от «Завершить урок» до сообщения в боте | 30–45 секунд |
