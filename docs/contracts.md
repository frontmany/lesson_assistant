# Контракты

Форматы сообщений между сервером, мини-приложением и ботом. В коде они описаны в `app/models.py`, примеры лежат в `webapp/mock/`. Меняем всё три места в одном PR, а `tests/test_contracts.py` следит, чтобы они совпадали.

## WebSocket `/ws/lessons/{lesson_id}`

Сервер шлёт события урока. Клиент различает их по полю `type`.

Пока урок не начат (`POST /api/lessons/{id}/start`), сервер проигрывает события из `webapp/mock/events.json`. Как только урок начат, мок останавливается.

Подключение: `?token=<сессия>` (см. «Вход»). Учителю уходят все события урока, ученику — только его `scale` и `analytics` для него или всего класса. Без сессии соединение закрывается с кодом 4403; при `DEV_AUTH=1` можно без неё, а ученика назвать `?id=`.

При подключении к идущему уроку сервер сразу присылает снимок: последнее `scale` и последнюю `utterance` каждого ученика, обычными событиями. Так после перезагрузки страницы шкалы не пустые. Если урок не идёт, снимка нет.

### `utterance` — реплика ученика

Видит только учитель.

```json
{"type": "utterance", "student_id": "artem_k", "t": 470.3,
 "text": "Ну, там флот строили", "kind": "response", "addressed": true}
```

| Поле | Значение |
|---|---|
| `t` | секунда от начала урока |
| `kind` | `answer` — ответ по теме, `initiative` — сам спросил или вызвался, `response` — ответил на обращение, `other` |
| `addressed` | ответ на обращение учителя |

### `scale` — ступень шкалы

Учитель получает события всех учеников, ученик — только свои.

```json
{"type": "scale", "student_id": "alisa_n", "level": 2,
 "label": "Есть ответ", "flags": ["quiet_but_precise"]}
```

| Поле | Значение |
|---|---|
| `level` | 1–4, только растёт в течение урока |
| `label` | «Пока тихо», «Есть ответ», «Участвуешь», «Активно на уроке» |
| `flags` | метки для учителя: `long_silence` — «давно не отвечал», `quiet_but_precise` — «редко, но развёрнуто». Ученику не показываются |

### `analytics` — выключатель

```json
{"type": "analytics", "enabled": false, "student_id": "sofya_l"}
```

`student_id: null` — для всего класса.

## Вход (#24)

Мини-приложение отправляет данные запуска MAX (`window.WebApp.initData`) в `POST /api/auth/max`. Сервер проверяет подпись токеном бота и возраст (не старше суток) и выдаёт сессию на 12 часов. Дальше запросы идут с заголовком `Authorization: Bearer <сессия>`, сокет — с `?token=`. Участника урока сервер определяет по сессии: id MAX из неё ищется в составе класса урока.

Права: состав, вход в звонок и `me` — участникам класса урока; начать и завершить урок, виртуальный класс, выключатель аналитики и сводка — учителю класса; карточка — учителю и самому ученику. Чужому — 403, без сессии — 401. При `DEV_AUTH=1` (разработка) без сессии можно назвать участника `?id=`, а без `?id=` запрос идёт от учителя.

## REST

| Метод | Путь | Ответ |
|---|---|---|
| `GET` | `/api/health` | состояние сервера |
| `POST` | `/api/auth/max` | `{"init_data": ...}` → `{"token": ..., "start_param": ...}`. `start_param` из кнопки бота: `c<id класса>` — учитель начинает урок класса, `l<id урока>` — открыть урок |
| `POST` | `/api/auth/ticket` | одноразовая ссылка в браузер, когда в MAX нет микрофона: `{"ticket": ...}`, живёт 10 минут |
| `POST` | `/api/auth/browser` | `{"ticket": ...}` → `{"token": ...}`, второй раз тот же билет — 401 |
| `POST` | `/api/classes/{id}/lessons` | «Начать урок»: урок класса, идущий или новый, `{"lesson_id": ...}`. Только учителю класса |
| `GET` | `/api/lessons/{id}/me` | кто я в уроке: `{"participant_id", "name", "role", "analytics", "ended", "demo"}`. `ended` — урок класса уже закончился: экран ведёт к классам, а не в звонок (демо-урок не «заканчивается», его можно смотреть заново). `demo` — демо-урок: экран объясняет, что смотреть, и входит без микрофона |
| `GET` | `/api/lessons/{id}/roster` | состав урока (`Roster`): если урок идёт с виртуальным классом — только ученики из записи, иначе состав класса |
| `POST` | `/api/lessons/{id}/virtual-class` | записанный урок заходит в звонок ботами; урок начинается, если ещё не идёт: `{"lesson_id": ..., "playing": true}`. Урок уже идёт без них — 409, записи нет — 503 |
| `DELETE` | `/api/lessons/{id}/virtual-class` | боты выходят, урок идёт дальше: `{"lesson_id": ..., "stopped": true}` |
| `GET` | `/api/lessons/{id}/join` | вход в звонок (`JoinInfo`) под своим id из сессии |
| `POST` | `/api/lessons/{id}/start` | учитель вошёл в звонок: ассистент заходит и слушает, ученики класса получают в боте «Урок начался»: `{"lesson_id": ..., "started": true}`, `false` — уже слушает. Демо-урок начинается сразу с записанным классом. `?virtual=true` — в составе урока ученики из записи (для `python -m app.cli virtual-class`) |
| `POST` | `/api/lessons/{id}/end` | ассистент выходит из звонка, очередь дораспознаётся, урок завершается, комната звонка закрывается у всего класса — у учеников экран «Урок завершён»: `{"lesson_id": ..., "ended": true}`, `false` — урок не идёт. Ответ приходит, когда всё распознано. Комната пуста 5 минут — урок завершается сам |
| `GET` | `/api/lessons/{id}/summary` | сводка учителю (`Summary`) |
| `GET` | `/api/lessons/{id}/cards/{student_id}` | карточка ученика (`StudentCard`) |
| `POST` | `/api/lessons/{id}/analytics` | включить или выключить аналитику (`AnalyticsState`) |

### `JoinInfo` — вход в звонок

```json
{"url": "ws://localhost:7880", "token": "eyJhbGciOi...",
 "participant_id": "artem_k", "name": "Артём К.", "role": "student"}
```

Токен LiveKit пускает в комнату `lesson-{id}`, identity в нём = `participant_id`. Участника нет в составе класса — ответ 404.

### `summary` — сводка учителю

```json
{"type": "summary", "lesson_id": "10a-history-05",
 "carried": ["ivan_i", "maria_s"], "dropped": ["dmitry_p"],
 "weak_topics": ["Табель о рангах"],
 "ask_next": [{"student_id": "artem_k", "topic": "Реформы Петра I",
               "question": "Зачем Петру понадобился Табель о рангах?"}]}
```

Пустые списки не показываем: если рекомендовать нечего, блока в сводке нет.

### `card` — карточка ученика

```json
{"type": "card", "lesson_id": "10a-history-05", "student_id": "artem_k",
 "level": 2, "went_well": ["Ответил про строительство флота"],
 "to_repeat": ["Табель о рангах"]}
```

Только своё, без оценок, рейтингов и сравнения с другими.

### Виртуальный класс в составе урока

Боты записанного урока входят в звонок с identity `virtual-<id>` (`virtual-ivan_i`), чтобы не выкинуть живых участников с тем же id. В `Roster` такого урока учеников класса нет, только ученики из записи с `"virtual": true` (до #45; потом будут вместе с живыми), а учитель из записи — в поле `virtual_teacher`: для конвейера он учитель. Реплики и шкала виртуальных учеников приходят под их `virtual-` id. Токен входа (`/join`) им не выдаётся.
