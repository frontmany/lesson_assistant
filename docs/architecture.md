# Архитектура

## Компоненты

| Компонент | Где | Что делает |
|---|---|---|
| Мини-приложение | `webapp/` | Звонок на LiveKit JS SDK, панель учителя, шкала ученика |
| LiveKit | контейнер `livekit` | SFU: принимает звук каждого участника и раздаёт остальным |
| Сервер приложения | `app/` | Токены входа, скрытый участник, конвейер, WebSocket событий, API, бот |
| Бот MAX | `app/bot/` | Вход в урок, рассылка сводки и карточек |

## Во время урока

Цель — шкала на экране меньше чем через 1,5 секунды после реплики.

```
браузер ──WebRTC──▶ LiveKit ──звук каждого участника──▶ sources/call.py (скрытый участник)
                                                              │ кадры 16 кГц, 30 мс, с id участника
                                                              ▼
                     pipeline: vad ──▶ asr ──▶ classify ──▶ scoring
                                                              │ Utterance, ScaleUpdate
                                                              ▼
                     app/ws ──WebSocket──▶ панель учителя и шкала ученика
```

## После урока

Цель — сводка через 30–45 секунд.

```
реплики из БД ──▶ нормировка по медиане пяти уроков ──▶ один запрос к LLM ──▶ сводка и карточки ──▶ бот MAX
```

## Вход в звонок

1. Мини-приложение запрашивает `GET /api/lessons/{id}/join?participant_id=...`.
2. Сервер проверяет, что участник есть в составе класса, и выдаёт адрес LiveKit и токен. identity в токене = id ученика.
3. Браузер заходит в комнату `lesson-{id}` и включает микрофон.
4. Ассистент заходит в ту же комнату с токеном `hidden`: остальные его не видят, он только слушает.

В MAX участник берётся из проверенных данных запуска (`window.WebApp.initData`), а не из параметра адреса.

## Решения

- **LiveKit, а не Janus**: готовый браузерный SDK и серверный Python SDK с приёмом звука каждого участника.
- **Сначала только звук**, видео — если останется время.
- **SQLite по умолчанию**, PostgreSQL и Redis — в compose.
- **Python 3.12**, распознавание на CPU (`base`, int8).
- **Неопознанный участник не засчитывается никому.**
- **Аудио не пишется на диск**, храним только реплики.

## Виртуальный класс

Инструмент разработки: записанные дорожки заходят в комнату ботами (`python -m app.cli virtual-class data/demo_lesson`). Для ассистента они неотличимы от людей, поэтому проверяется весь путь. Для замеров качества тот же урок прогоняется без звонка: `python -m app.cli replay data/demo_lesson`.
