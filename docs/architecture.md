# Архитектура

## Части системы

Приложение внутри MAX лежит в папке `webapp`. Это стартовая страница с классами и звонок учителя и ученика на LiveKit.

LiveKit это сервер звонков. Он принимает звук каждого участника и раздаёт его остальным.

Сервер лежит в папке `backend`. Он выдаёт токены входа в звонок, запускает невидимого ассистента и конвейер распознавания, рассылает события урока и ведёт бота MAX.

Бот MAX ведёт классы, зовёт учеников на урок и после урока присылает сводку и карточки.

## Во время урока

```
браузер ──WebRTC──▶ LiveKit ──звук каждого участника──▶ ассистент
                                                          │
                                                          ▼
                    поиск речи ──▶ распознавание ──▶ тип реплики ──▶ шкала
                                                          │
                                                          ▼
                    WebSocket ──▶ панель учителя и шкала ученика
```

Ассистент входит в комнату урока скрытым участником. Его никто не видит, он только слушает. Звук каждого участника приходит отдельной дорожкой, поэтому реплика всегда приписана тому, кто говорил. Поиск речи выделяет фразы, модель GigaAM v3 распознаёт их на процессоре, правила определяют тип реплики, а шкала пересчитывает ступени. Шкала обновляется примерно через секунду после конца фразы.

## После урока

Учитель завершает урок, и ассистент выходит из звонка. Сервер сохраняет реплики и ступени и сразу закрывает урок. Сводка и карточки собираются отдельно. Их пишет GigaChat, а без ключа или при ошибке они строятся по шаблону из шкалы. Бот присылает сводку учителю и карточки ученикам.

## Вход

Приложение открывается кнопкой бота. Сервер проверяет подпись данных запуска MAX токеном бота и узнаёт человека по аккаунту. Участник звонка всегда берётся из сессии, а не из адреса страницы. Токен LiveKit пускает только в комнату своего урока и только участника этого класса.

Ученик публикует в звонок только микрофон и камеру. Показывать экран может только учитель.

## Хранение

По умолчанию данные лежат в SQLite, в Docker Compose в PostgreSQL. Аудио на диск не пишется.

## Записанный класс

Для демо и отладки записанный урок заходит в звонок ботами, по боту на ученика. Для ассистента они неотличимы от людей, поэтому так проверяется весь путь от звонка до сводки.
