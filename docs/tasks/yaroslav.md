# Ярослав — разработчик, звонок → конвейер

Зона: LiveKit, скрытый участник, распознавание, конвейер, Docker. Ревью кода остальных.

## Задачи

| Дни | Задача | Результат |
|---|---|---|
| 1–2 | `docker compose up`: приложение и LiveKit. Две вкладки (`teacher.html` и `student.html?id=artem_k`) слышат друг друга | Звонок работает локально |
| 3–4 | `sources/call.py`: скрытый участник получает звук каждого участника | В логе кадры с id каждого говорящего |
| 4–5 | `vad.py` и `asr.py`: отрезки речи → текст | Говорю в звонке — реплика с моим id приходит в панель |
| 5–7 | `runner.run_call` на нескольких потоках, `POST /lessons/{id}/start` | Реплики всех участников приходят в панель |
| 6–8 | `virtual_class.py`: записанные дорожки заходят в звонок ботами | Урок проигрывается в звонке без людей |
| 7–9 | Подключить `classify.py`, `scoring.py`, БД и сводку | Урок от «Начать» до сводки проходит целиком |
| 9–11 | Нагрузка: 6–10 участников, задержка ниже 1,5 секунды | Таблица задержек по числу участников |
| 10–12 | Развёртывание вместе с Фёдором (`docs/deploy.md`) | Звонок работает с телефонов в мобильной сети |
| 12–14 | `PRELOAD_MODEL=1`, `pip freeze` в `requirements.txt`, прогоны | Сборка с нуля на чистой машине работает |
