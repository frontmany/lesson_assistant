# Илья — аналитик, данные и качество

Зона: на чём система учится и как мы проверяем, что она работает.

## Задачи

| Дни | Задача | Результат |
|---|---|---|
| 1–2 | Сценарий урока на 5–7 минут с профилями учеников | Раздел в `docs/scenario.md` |
| 3–4 | Запись урока: каждый пишет свой микрофон | Дорожки в `data/demo_lesson/tracks/` |
| 4–6 | Ручная разметка реплик | `data/demo_lesson/ground_truth.csv` |
| 5–8 | Правила классификации и скоринга: веса, пороги ступеней, норма, «давно не отвечал» | Таблица правил, затем с Ярославом — `scoring.py` и тесты |
| 8–10 | Пять прошлых уроков и промпты сводки и карточки | `history_seed.json`, `prompts/*.md`, сводка помещается на экран |
| 9–12 | Замеры на записи: распознавание, тип реплики, задержка | `analytics/` и таблица с цифрами |
| 10–14 | Замеры на живых звонках по пятницам: реплики, приписанные не тому, задержка в мобильной сети | Сравнение «запись против живого звонка» в README |
