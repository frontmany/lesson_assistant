# Варвара — дизайнер

Зона: как выглядит всё, что видят учитель и ученик. Макеты экранов, вид сообщений бота, оформление. Код пишет Фёдор, Варвара принимает экраны по макетам.

## Задачи

| Дни | Задача | Результат |
|---|---|---|
| 1–3 | Экран звонка учителя в Figma: участники, кто говорит, панель класса, индикатор «Аналитика активна», выключатель | Макет согласован, экспорт в `design/screens/` |
| 2–4 | Состояния звонка: вход, микрофон включён и выключен, подключение, связь пропала, нет доступа к микрофону | Макеты для телефона, ширина 375 px |
| 3–5 | Экран ученика в звонке: своя шкала из четырёх ступеней, выбор роли | Макеты для телефона |
| 5–7 | Вид сводки учителю и карточки ученика в боте, тексты кнопок и приветствия | Готово для Фёдора |
| 6–8 | Аватар и обложка бота, иконка мини-приложения | Файлы в `design/bot/` |
| 8–12 | Дизайн-ревью готовых экранов: тёмная тема, длинные имена, 30 учеников, пустые блоки, слабая связь | Список правок в issues |
| 12–14 | Скриншоты для README | Скриншоты в `design/screens/` |

## Правила интерфейса

- Ученик видит только свою шкалу. Никаких чужих шкал и мест в рейтинге.
- Подписи ступеней: «Пока тихо», «Есть ответ», «Участвуешь», «Активно на уроке».
- Тон нейтральный: не «молодец» и не «тебя не слышно».
- Индикатор «Аналитика активна» виден весь урок.
- Пустой блок не показываем.
- Какие данные есть у экрана, описано в `docs/contracts.md`. Нужно новое поле — обсуди с Фёдором.
