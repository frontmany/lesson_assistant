# Фёдор — капитан, мини-приложение, бот, сервер, сдача

Зона: код мини-приложения по макетам Варвары, бот MAX, развёртывание, документация и сдача. Доска задач и созвоны.

## Задачи

| Дни | Задача | Результат |
|---|---|---|
| 1–2 | Репозиторий на GitHub, доска задач, токен MAX. **Проверить звонок во встроенном браузере MAX**: микрофон и звук | Понятно, где живёт звонок: в MAX или в браузере по ссылке |
| 3–5 | `app/bot/max_bot.py`: `/start`, кнопки ролей, «Начать урок», открытие мини-приложения | Бот открывает урок |
| 3–7 | `webapp/`: экран звонка (вход, микрофон, кто говорит, состояние связи, ошибки) и панель учителя по макету | Урок проходит в звонке, панель обновляется |
| 6–9 | `webapp/`: экран ученика, выключатель аналитики, выбор роли | Шкала только растёт, выключатель шлёт событие |
| 8–10 | `pipeline/summary.py`: LLM и шаблонный вариант, рассылка сводки и карточек | После урока бот присылает сводку |
| 9–11 | MAX Bridge: участник из проверенных `initData` в `/join` | Нельзя зайти в урок за другого |
| 10–12 | Развёртывание с Ярославом: VM, HTTPS, LiveKit с TURN (`docs/deploy.md`) | Звонок работает с телефонов в мобильной сети |
| 12–14 | README, проверка сборки с нуля, отправка работы | Работа сдана за сутки до дедлайна |
