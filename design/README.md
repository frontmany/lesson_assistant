# Дизайн

Владелец: Варвара.

- `screens/` — макеты экранов в PNG: выбор роли, урок учителя, урок ученика, сводка и карточка в боте.
- `bot/` — аватар и обложка бота.

Инструмент для макетов любой, Figma не обязательна: подходит и HTML-макет. Исходники `.fig` в репозиторий не кладём, только экспорт в PNG.

Стиль продолжает презентацию первого этапа: тёмно-синий `#1f3150`, оливковый `#5b6b3f`, светлый фон. Токены — в `webapp/css/tokens.css`.
