# Дизайн

Владелец: Варвара.

Экраны мини-приложения в `screens/` — это настоящий интерфейс. Макеты звонка собраны на стилях и сетке плиток самого приложения (`webapp/css/*`, `webapp/js/stage.js`), только участники и шкалы в них подставные. Стартовые экраны сняты с работающего приложения. Поэтому макет и приложение не расходятся: поменяли стиль в `webapp/css` — макет поменялся вместе с ним.

Пересобрать все PNG:

```bash
python -m http.server 8090
```

```bash
docker compose run -d --rm --name la-dev -e DEV_AUTH=1 -e MAX_BOT_TOKEN= -e SESSION_SECRET=screens -p 8001:8000 app
```

```bash
node scripts/screens.mjs
```

Первая команда открывает макеты, вторая — копию приложения без бота для стартовых экранов, третья снимает всё через Edge или Chrome без окна. `node scripts/screens.mjs start-` — только файлы, в имени которых есть `start-`.

Размеры: компьютер `-d-` — 1280×800, телефон `-m-` — 375×812 @2x. Тёмная тема — суффикс `-dark`.

- `bot/` — аватар бота, обложка `cover.png` (16:9) и квадратная `start-card.png` — картинка в первом сообщении `/start`: MAX показывает её почти квадратом.

- `teacher-call.html` — звонок учителя. Состояние задаётся в адресе. Экспорт: `screens/teacher-call-d-*.png`, `screens/teacher-call-m-*.png`.

  | Состояние | Адрес после `teacher-call.html` | Файлы |
  |---|---|---|
  | Учитель один, панели класса нет | `?n=1` | `d-n1`, `m-n1` |
  | Учитель и ученик | `?n=2` | `d-n2`, `m-n2` |
  | Шесть человек: камера и без, выключенный микрофон, говорящий, панель со шкалами | `?n=6` | `d-n6`, `m-n6`, `-dark` |
  | Телефон: панель класса открыта снизу | `?n=6&panel=1` | `m-n6-sheet` |
  | Тридцать: страницы плиток, строки панели сжаты, фильтры | `?n=30` | `d-n30`, `m-n30`, `m-n30-sheet` |
  | Панель свёрнута | `?n=30&panel=0` | `d-n30-panel-closed` |
  | Учитель показывает экран | `?n=6&share=1` | `d-share`, `m-share` |
  | Начало урока, шкал ещё нет | `?n=6&mode=start` | `d-start`, `m-start` |
  | Меню ученика: выключатель аналитики | `?n=6&menu=s1` | `d-menu`, `m-menu` |

  Как работает экран:
  - Плитки всегда одной формы: 16:9 на компьютере, 4:3 на телефоне, не мельче 260 px (на телефоне 150 px). Кто не помещается, уходит на следующую страницу: стрелки по бокам, на телефоне свайп и точки снизу. Сетка стоит по центру сцены.
  - Подписей на плитках нет: имя во всплывающей подсказке. Говорящий — с зелёной обводкой, выключенный микрофон — значок в углу.
  - Нижняя панель: микрофон, камера, показ экрана, «Завершить урок».
  - Панель класса: у ученика шкала из четырёх сегментов, метки «давно не отвечал» и «редко, но развёрнуто», последняя засчитанная реплика. С девяти учеников строки сжаты, сверху фильтры, первыми идут ученики с метками. Сворачивается стрелкой в шапке; на телефоне панель снизу.
  - Под заголовками серых пояснений нет: только ошибка, если она есть.

- Состояния звонка — тот же `teacher-call.html` с `?state=`. Экспорт: `screens/call-state-d-*.png`, `screens/call-state-m-*.png`.

  | Состояние | Адрес | На экране |
  |---|---|---|
  | До входа | `?state=lobby` | «Готовы войти?», кнопка «Войти в урок», предпросмотр с микрофоном и камерой |
  | Подключаемся | `?state=connecting` | «Подключаемся к уроку», неактивная кнопка «Подключаемся…» |
  | Микрофон выключен | `?state=muted` | Сообщение «Микрофон выключен. Ученики вас не слышат», кнопка микрофона красная |
  | Связь пропала | `?state=reconnecting` | Плашка «Связь пропала. Переподключаемся…», плитки приглушены |
  | Нет микрофона | `?state=nomic` | «Нет доступа к микрофону», «Открыть настройки MAX», «Попробовать снова», «Войти без микрофона» |
  | Урок завершён | `?state=ended` | «Урок завершён», длительность и число учеников, «К классам» |
  | Открыт закончившийся урок | `?state=over` | «Урок уже закончился», «К классам» |
  | Ссылка устарела | `?state=fail` | «Не удалось открыть урок», текст ошибки, «Открыть из чата с ботом» |

- `student-call.html` — звонок ученика: та же сцена, что у учителя, без панели класса. Своя шкала — звезда «AI» и четыре сегмента внизу своей плитки. Экспорт: `screens/student-call-m-*.png`, `screens/student-call-d-l3.png`.

  | Состояние | Адрес после `student-call.html` | Файл |
  |---|---|---|
  | Ступени «Пока тихо» … «Активно на уроке» | `?level=1` … `?level=4` | `m-l1` … `m-l4`, `m-l3-dark` |
  | Микрофон выключен | `?level=2&mic=0` | `m-muted` |
  | Учитель выключил аналитику: шкала серая | `?ana=off` | `m-ana-off`, `m-ana-off-dark` |
  | Учителя ещё нет, ученик один | `?teacher=0&n=0` | `m-alone` |
  | Учитель показывает экран | `?share=1` | `m-share` |
  | Компьютер | `?level=3&n=6` | `d-l3` |

  Порядок плиток: учитель, ты, одноклассники. Пустой плитки «учитель ещё не вошёл» нет. Показывать экран ученик не может: это право учителя и в интерфейсе, и в токене звонка.

- `bot-registration.html` — переписка с ботом: регистрация и управление классом. Тексты и кнопки прошли ru-text, Фёдор переносит их в бота как есть, включая неразрывные пробелы (`&nbsp;` в разметке). Без адреса показаны все шаги, один шаг — `?step=1…14`. Рядом с каждым шагом заметка: когда приходит сообщение и что делает кнопка.

  | Шаг | Адрес после `bot-registration.html` | Что показано |
  |---|---|---|
  | 1 | `?step=1` | Незнакомый человек: «Я учитель», «Я ученик» |
  | 2 | `?step=2` | Создание класса: название и предмет |
  | 3 | `?step=3` | Ссылка-приглашение и код класса: «Поделиться», «Ученики», «Новая ссылка» |
  | 4 | `?step=4` | Ученик входит по ссылке, подтверждает имя |
  | 5 | `?step=5` | «Я ученик» без ссылки: бот просит код класса |
  | 6 | `?step=6` | Учителю: ученик вошёл, «Убрать из класса» и «Вернуть» |
  | 7 | `?step=7` | Выход ученика и уведомление учителю |
  | 8 | `?step=8` | Новая ссылка |
  | 9 | `?step=9` | Удаление класса, «Вернуть» в течение 30 дней |
  | 10 | `?step=10` | «Урок начался» |
  | 11 | `?step=11` | Человек в нескольких классах |
  | 12 | `?step=12` | Знакомый учитель пишет боту: классы и действия, в том числе «Удалить класс» |
  | 13 | `?step=13` | Знакомый ученик пишет боту: класс и «Выйти из класса» |
  | 14 | `?step=14` | Старая ссылка или ссылка удалённого класса |

- `bot-summary.html` — сообщения бота после урока (issue #15): сводка учителю и карточка ученика. Телефон 375 px, палитра второго варианта экрана ученика (его файл `student-call-alt.html` убран из репозитория в #52), но фон светлый молочный `#FBF8F0`, а шапка, кнопки и свои сообщения пастельного оливкового `#C8D2AA` / `#E1E7CE`; цвета заданы прямо в файле; тема системная, `?theme=dark|light` перекрывает. Без адреса показаны все сцены, одна сцена — `?scene=1…9`, без рамки для экспорта — `&bare=1`. Тексты прошли ru-text, неразрывные пробелы (`&nbsp;`) переносятся в бота как есть. Форматирование в MAX ограничено, поэтому в тексте только жирные названия блоков и пустая строка между блоками: ни таблиц, ни заголовков, ни цвета, ни эмодзи. Экспорт: `screens/bot-summary-m-*.png` (@2x), тёмная тема у сцен 1, 4 и 5 с суффиксом `-dark`.

  | Сцена | Адрес после `bot-summary.html` | Что показано | Файл |
  |---|---|---|---|
  | 1 | `?scene=1` | Сводка учителю: вытянули урок, выпали, слабые темы, «Спросить в следующий раз» с готовым вопросом | `summary`, `summary-dark` |
  | 2 | `?scene=2` | Первый урок: пустые блоки скрыты | `summary-hidden` |
  | 3 | `?scene=3` | Данных мало, выводов нет | `summary-empty` |
  | 4 | `?scene=4` | Класс на 28 человек: «и ещё N», не больше трёх тем и вопросов | `summary-long`, `summary-long-dark` |
  | 5 | `?scene=5` | Карточка ученика: «Что получилось», «Что повторить» | `card`, `card-dark` |
  | 6 | `?scene=6` | Карточка с одним блоком | `card-short` |
  | 7 | `?scene=7` | Сводка ещё готовится | `pending` |
  | 8 | `?scene=8` | Сводку собрать не удалось, «Собрать снова» | `failed` |
  | 9 | `?scene=9` | Меню знакомого учителя с кнопкой «Последняя сводка» | `menu` |

  Правила: сводка помещается на один экран телефона вместе с кнопками. Пустой блок не показываем. Карточка на «ты», без оценок, баллов и сравнения с классом, без глаголов прошедшего времени: пол ученика бот не знает. Поле `level` в карточке не выводим. Ученику с выключенной аналитикой карточку не шлём, при двух пустых списках тоже.

- Стартовая страница и классы — `webapp/index.html` на работающем приложении, телефон 375 px. Экспорт: `screens/start-*.png`.

  | Экран | Файл |
  |---|---|
  | Выбор роли «Я учитель» / «Я ученик» | `start-welcome` |
  | Мои классы учителя | `start-teacher`, `start-teacher-dark` |
  | Класс: ученики, «Пригласить», «Начать урок» | `start-class` |
  | Пригласить: ссылка и код класса | `start-invite` |
  | Новый класс | `start-create` |
  | Мои классы ученика | `start-student` |

  Ученика убирают сразу, без вопроса, и в боте, и в приложении: «Вернуть» возвращает его в класс. Подтверждение есть только при удалении класса.

Инструмент для макетов любой, Figma не обязательна: подходит и HTML-макет. Исходники `.fig` в репозиторий не кладём, только экспорт в PNG.

Стиль взят из презентации первого этапа: тёмно-синий `#1f3150`, оливковый `#5b6b3f`, светлый фон. Все цвета и тени макета берутся из токенов в `webapp/css/tokens.css`, своих значений в `teacher-call.html` нет. Шрифт Onest лежит в `webapp/fonts/` вместе с лицензией и подключается в `tokens.css`. Для тёмной темы переопределены все токены, где значение светлой не подходит.

Названия в интерфейсе: «Участники» — подпись кнопки в нижней панели, «Панель класса» — название самой панели. Аналитика везде «включена» или «выключена».
