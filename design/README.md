# Дизайн

Снимки экранов в `screens` это настоящий интерфейс. Макеты звонка `teacher-call.html` и `student-call.html` собраны на стилях и сетке самого приложения, подставные в них только участники и шкалы. Стартовые экраны сняты с работающего приложения. Поэтому макет и приложение не расходятся.

## Как пересобрать снимки

Нужны Node, Edge или Chrome и запущенная копия приложения без бота. Первая команда открывает макеты, вторая поднимает копию приложения, третья заводит в ней демо учителя с классами, четвёртая снимает экраны.

```bash
python -m http.server 8090
docker compose run -d --rm --name la-dev -e DEV_AUTH=1 -e MAX_BOT_TOKEN= -e SESSION_SECRET=screens -p 8001:8000 app
docker exec -i la-dev python - < scripts/screens-seed.py
node scripts/screens.mjs
```

Снимки компьютера имеют размер 1280 на 800, снимки телефона 375 на 812 с двойной плотностью. В имени файла `d` означает компьютер, `m` телефон, а суффикс `dark` тёмную тему.

## Что есть в снимках

Звонок учителя снят для одного, двух, шести и тридцати участников, со свёрнутой и открытой панелью класса, с показом экрана, в начале урока до первых реплик и с меню выключателя аналитики. Состояние задаётся в адресе макета, например `teacher-call.html?n=30&panel=0`.

Состояния звонка сняты с префиксом `call-state`. Это вход, подключение, выключенный микрофон, потеря связи, нет микрофона, урок завершён, урок уже закончился и устаревшая ссылка.

Звонок ученика снят на всех четырёх ступенях шкалы, с выключенным микрофоном, с выключенной учителем аналитикой, в одиночку до прихода учителя и с показом экрана учителя.

Стартовые экраны сняты с префиксом `start`. Это выбор роли, классы учителя, экран класса, приглашение, новый класс и классы ученика.

## Бот

В `bot` лежат аватар и обложки бота. Квадратная `start-card.png` стоит в первом сообщении на команду start, потому что MAX показывает картинку почти квадратом. Макеты переписки с ботом лежат в `bot-registration.html` и `bot-summary.html`.

## Стиль

Цвета и тени берутся из `webapp/css/tokens.css`, шрифт Onest лежит в `webapp/fonts`. У макетов своих стилей нет, кроме картинки вместо видео камеры в `mock-call.css`.
