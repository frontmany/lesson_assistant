# Дизайн

Владелец: Варвара.

- `screens/` — макеты экранов в PNG: выбор роли, урок учителя, урок ученика, сводка и карточка в боте.
- `bot/` — аватар и обложка бота.
- `teacher-call.html` — макет экрана звонка учителя в HTML на токенах из `webapp/css/tokens.css`. Состояние задаётся в адресе, на окне уже 700 px включается вид для телефона. Экспорт лежит в `screens/`: `teacher-call-d-*.png` (десктоп 1280×800) и `teacher-call-m-*.png` (телефон 375 px, @2x).

  | Состояние | Адрес после `teacher-call.html` | Файлы |
  |---|---|---|
  | Один человек в звонке, панели класса нет | `?n=1` | `d-n1`, `m-n1` |
  | Двое | `?n=2` | `d-n2`, `m-n2` |
  | Шесть: плитки с камерой и без, без микрофона, говорящий, панель со шкалами | `?n=6` | `d-n6`, `m-n6` |
  | Телефон: панель класса открыта шторкой | `?n=6&panel=1` | `m-n6-sheet` |
  | Тридцать: плитки не помещаются, страницы 1 / 2 (на телефоне 1 / 5), панель сжата в строки | `?n=30` | `d-n30`, `m-n30`, `m-n30-sheet` |
  | Панель свёрнута, плитки на всю ширину | `?n=30&panel=0` | `d-n30-panel-closed` |
  | Демонстрация экрана | `?n=6&share=1` | `d-share`, `m-share` |
  | Начало урока, шкал ещё нет | `?n=6&mode=start` | `d-start`, `m-start` |
  | Меню за троеточием, выключатель аналитики ученика | `?n=6&menu=artem_k` | `d-menu`, `m-menu` |

  Как работает экран:
  - Нижняя панель: микрофон, камера, показ экрана, чат, участники (открывает и закрывает панель класса), выход.
  - Аналитика обозначена маленьким значком в углу своей плитки. Его подсказка: «Аналитика активна».
  - Плитки не помещаются — разбиваются на страницы: 16 на десктопе, 6 на телефоне. Внизу показано, какая страница и сколько людей всего.
  - Панель на 30 учеников: строки сжаты, внутри панели прокрутка, сначала «давно не отвечал» и «тихий, но точный», сверху фильтры. Свернуть — стрелкой в шапке панели или кнопкой «Участники».
  - Начало урока: у учеников только имена, без шкал, а подсказка говорит, что шкалы появятся позже.
  - Выключатель аналитики ученика спрятан в меню за троеточием. Общего выключателя на класс нет.

- Состояния звонка — тот же `teacher-call.html` с `?state=`. Экспорт: `screens/call-state-d-*.png` (десктоп) и `screens/call-state-m-*.png` (телефон 375 px).

  | Состояние | Адрес | Текст на экране |
  |---|---|---|
  | До входа | `?state=lobby` | «Готовы войти?» · «Проверьте микрофон и камеру. Аналитика включится, когда вы войдёте в урок.» · кнопка «Войти в урок». В превью — «Микрофон работает» с уровнем звука |
  | Подключаемся | `?state=connecting` | «Подключаемся к уроку» · «Обычно это занимает несколько секунд.» · неактивная кнопка «Подключаемся…» |
  | В уроке | `?state=live` (или без параметра) | Экран звонка без дополнительных сообщений |
  | Микрофон выключен | `?state=muted` | Всплывающее сообщение «Микрофон выключен. Ученики вас не слышат», кнопка микрофона красная, на своей плитке значок |
  | Связь пропала, переподключаемся | `?state=reconnecting` | Плашка «Связь пропала. Переподключаемся…», плитки приглушены, в панели класса «Шкалы обновятся, когда связь вернётся.» |
  | Браузер не дал микрофон | `?state=nomic` | «Нет доступа к микрофону» · «Разрешите микрофон в настройках браузера или MAX и попробуйте снова. Без микрофона ученики вас не услышат.» · «Попробовать снова», «Войти без микрофона» |
  | Урок завершён | `?state=ended` | «Урок завершён» · длительность и число учеников · «Сводка по уроку придёт в чат с ботом примерно через минуту.» · «Вернуться в чат» |

  Сообщение о выключенном микрофоне видно несколько секунд после нажатия. Плашка о переподключении держится, пока связь не вернётся.

Инструмент для макетов любой, Figma не обязательна: подходит и HTML-макет. Исходники `.fig` в репозиторий не кладём, только экспорт в PNG.

Стиль продолжает презентацию первого этапа: тёмно-синий `#1f3150`, оливковый `#5b6b3f`, светлый фон. Токены — в `webapp/css/tokens.css`.
