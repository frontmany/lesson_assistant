# Промо-ролик «Сферум AI»

62 секунды, 1920×1080, 30 кадров в секунду, MP4. Озвучки нет: весь текст идёт титрами на русском. Ролик собран в Remotion по подходу [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft): кадры рисует код, нейросеть видео не генерирует.

Вид продолжает продукт: шрифт Onest, цвета из `webapp/css/tokens.css` в тёмной теме (фон `#141b27`, поверхности `#1c2535`, акцент `#a6b58a`). Экраны взяты из актуальных снимков в `design/screens` (их делает `scripts/screens.mjs`). Имена в кадре только из демо-урока: Иван И., Мария С., Алиса Н., Артём К., Софья Л. Логотипа Сферума нет.

В кадрах 3 и 5 панель «Класс» нарисована кодом (`src/Window.tsx`) поверх актуального экрана, потому что на статичной картинке шкала не растёт. Строки панели повторяют `.stu` из `webapp/css/call.css`: имя, пометка рядом, четыре сегмента, последняя реплика. В кадрах 4 и 5 справа увеличена плитка ученика со звездой AI и четырьмя сегментами.

## Звук

Фоновая музыка (House Vibez) тихая (16% громкости): ровный бит без слов, в конце затухает. Звуки на стыках кадров, щелчок при клике в кадрах 2 и 5, удар в финале. Источники и лицензии: `CREDITS.md`.

## Как собрать

```bash
cd video
npm install
npm run dev      # студия Remotion с предпросмотром
npm run render   # out/promo.mp4
```

Экраны и шрифт `npm run dev` и `npm run render` сначала копируют скриптом `scripts/assets.mjs` из `design/screens` и `webapp/fonts` в `public/` (в git эти копии не лежат). Если экраны приложения поменяются, перезапустите `scripts/screens.mjs` и пересоберите ролик. Только снимки чатов бота `public/screens/reg-*-dark.png` лежат в git: их сняли с `design/bot-registration.html`.
