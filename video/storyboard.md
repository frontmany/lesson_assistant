# Промо-ролик «Урок в MAX»

62 секунды, 1920×1080, 30 кадров в секунду, MP4. Озвучки нет: весь текст идёт титрами на русском. Ролик собран в Remotion по подходу [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft): кадры рисует код, нейросеть видео не генерирует.

Вид продолжает продукт: шрифт Onest, цвета из `webapp/css/tokens.css` (тёмно-синий `#1f3150`, оливковый `#5b6b3f`, светлый фон `#f2efe8`). Экраны взяты из макетов в `design/`. Имена в кадре только из демо-урока: Иван И., Мария С., Алиса Н., Артём К., Софья Л. Логотипа Сферума нет.

В кадрах 3 и 5 панель «Класс» нарисована кодом (`src/Window.tsx`) поверх экрана макета, потому что на статичной картинке шкала не растёт. Вёрстка панели повторяет `teacher-call.html`.

## Звук

Фоновая музыка (House Vibez) тихая (16% громкости): ровный бит без слов, в конце затухает. Звуки на стыках кадров, щелчок при клике в кадрах 2 и 5, удар в финале. Источники и лицензии: `CREDITS.md`.

## Как собрать

```bash
cd video
npm install
npm run dev      # студия Remotion с предпросмотром
npm run render   # out/promo.mp4
```

Экраны лежат в `public/screens`. Это копии из `design/screens` и два снимка чата из `design/bot-registration.html`. Если макеты поменяются, обновите файлы.
