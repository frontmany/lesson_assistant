# Мини-приложение

Веб-страницы, которые открываются из бота MAX. Код: Фёдор. Макеты: Варвара (`design/screens/`).

## Экраны и файлы

| Файл | Что это |
|---|---|
| `index.html` + `js/start.js` | стартовая страница: узнаёт человека по данным MAX и открывает урок по кнопке бота; без урока — классы, «Посмотреть демо» |
| `teacher.html` + `js/teacher.js` | урок глазами учителя: звонок, панель класса, выключатель аналитики ученика |
| `student.html` + `js/student.js` | урок глазами ученика: учитель, одноклассники, своя шкала, «аналитика выключена» |
| `js/call.js` | вход в звонок на LiveKit JS SDK, микрофон, кто говорит |
| `js/mic.js` | доступ к микрофону в MAX, запасной вход через браузер |
| `js/lesson.js` | вход по данным MAX, запросы к API, события урока по WebSocket |
| `css/tokens.css`, `css/call.css`, `css/student.css` | цвета, шрифты, экраны звонка учителя и ученика |
| `mock/` | события урока, сводка, карточки — пока конвейера нет |

Сводка учителю и карточка ученика приходят сообщениями в бот, их вид рисует Варвара.

## Как запустить

```bash
docker compose up --build
```

Откройте http://localhost:8000/teacher.html и во второй вкладке http://localhost:8000/student.html?id=artem_k (при `DEV_AUTH=1`), в обеих нажмите «Войти в урок». Поменял код или моки — обнови страницу, сборки нет.

## Звонок

- LiveKit JS SDK подключается в HTML с CDN (`livekit-client@2.22.3`) и даёт глобальный `LivekitClient`.
- Вход в звонок — только по нажатию кнопки: без жеста пользователя браузер не даст микрофон и звук.
- Микрофон браузер даёт только на `localhost` или по `https`. Со страницы по `https` LiveKit должен быть по `wss` (см. `docs/deploy.md`).
- Сначала проверить, работает ли звонок во встроенном браузере MAX. Если нет — открываем мини-приложение по ссылке в обычном браузере.

## Правила

- Экраны делаем по макетам Варвары. Расходится с макетом — сначала обсуди с ней.
- Цвета и шрифты — только через переменные в `css/tokens.css`.
- Тон текстов нейтральный: «Пока тихо», а не «Тебя не слышно».
- Ученик никогда не видит чужие шкалы и рейтинги.
- Пустой блок не показываем.
- Экраны работают на ширине 375 px: в MAX их откроют с телефона.
- Нужно новое поле в событиях — меняем контракт (`docs/contracts.md`).

## Мост MAX

Данные запуска лежат в `window.WebApp.initData` (MAX Bridge, https://dev.max.ru/docs/webapps/bridge). По ним сервер должен определять участника в `/api/lessons/{id}/join`, а не по `?id=` в адресе. Задача Фёдора.
