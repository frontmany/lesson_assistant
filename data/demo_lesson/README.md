# Демо-урок

Записанный урок: на нём отлаживают конвейер и считают цифры качества. Владелец: Илья.

Урок можно прогнать без звонка (`python -m app.cli replay data/demo_lesson`) или завести в звонок ботами (`python -m app.cli virtual-class data/demo_lesson`).

## Состав

- `roster.json` — класс, тема и участники. id участника = имя его дорожки.
- `tracks/` — дорожки: `teacher.wav`, `ivan_i.wav`, `maria_s.wav` и так далее.
- `ground_truth.csv` — ручная разметка реплик, эталон для замеров качества.
- `history_seed.json` — пять прошлых уроков для нормы и рекомендаций.

## Как записывать

1. Сценарий урока на 5–7 минут — в `docs/scenario.md`, раздел «Сценарий урока».
2. Все сидят в одном звонке, каждый пишет **свой** микрофон отдельно (Audacity, OBS или диктофон в наушниках), чтобы голоса не попадали в чужие дорожки.
3. Начать запись одновременно и хлопнуть в ладоши: по хлопку дорожки потом выравниваются.
4. Экспорт: WAV, 16 кГц, моно, все дорожки одной длины, имя файла = id из `roster.json`.

Профили учеников, которые должны получиться:

| Ученик | Профиль |
|---|---|
| Иван И. | активный, много содержательных ответов |
| Мария С. | задаёт вопросы сама |
| Артём К. | молчит, отвечает только на обращение, коротко |
| Софья Л. | отвечает на обращение, много слов, мало по делу |
| Алиса Н. | говорит редко, но точно |
| Дмитрий П. | молчит весь урок |

## Разметка `ground_truth.csv`

| Колонка | Что писать |
|---|---|
| `speaker_id` | id из `roster.json` |
| `start_s`, `end_s` | начало и конец реплики в секундах |
| `text` | что сказано, дословно |
| `kind` | `answer`, `initiative`, `response` или `other` |
| `addressed` | `1`, если это ответ на обращение учителя, иначе `0` |

Если дорожки весят больше 50 МБ, в репозиторий их не кладём, а даём ссылку здесь.
